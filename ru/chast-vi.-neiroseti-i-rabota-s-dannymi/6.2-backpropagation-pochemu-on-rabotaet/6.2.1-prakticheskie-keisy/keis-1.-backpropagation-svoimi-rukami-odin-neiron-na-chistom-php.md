# Кейс 1. Backpropagation своими руками – один нейрон на чистом PHP

Теория backpropagation может показаться сложной, пока мы смотрим только на формулы.

Поэтому в этом кейсе мы сделаем то, что обычно скрывают ML-библиотеки: реализуем обучение нейрона самостоятельно.

Без RubixML. Без готового алгоритма обучения. Без TensorFlow или PyTorch.

Только PHP, несколько формул и немного градиентной математики.

В результате у нас будет небольшой класс `Neuron`, который умеет:

* принимать входные данные
* делать prediction
* вычислять ошибку
* считать градиенты
* изменять свои параметры
* повторять этот процесс много раз

Это будет самый маленький пример настоящего обучения нейронной сети.

### Цель кейса

В предыдущей главе мы реализовали перцептрон и увидели основной принцип работы нейрона:

```
входы → веса → взвешенная сумма → активация → результат
```

Но у нашего перцептрона был один важный недостаток. Мы сами задавали веса.

Например:

```php
$weight = 0.5;
```

Или:

```php
$weight = -0.3;
```

Но в настоящем машинном обучении мы не хотим вручную искать правильные значения.

Мы хотим дать модели данные и сказать:

> Найди такие параметры, при которых ошибка будет минимальной.

И здесь появляется [backpropagation](../../../vvedenie/glossarii.md#backpropagation-obratnoe-rasprostranenie-oshibki).

Backpropagation позволяет определить, как каждый параметр модели повлиял на ошибку.

После этого параметры можно немного изменить.

Процесс выглядит так:

```
данные
  ↓
forward pass
  ↓
prediction
  ↓
loss
  ↓
backpropagation
  ↓
gradients
  ↓
update
  ↓
новые параметры
  ↓
следующий шаг
```

В этом кейсе мы реализуем весь этот цикл самостоятельно.

### Сценарий: нейрон для обнаружения фишинговых писем

Представим очень простой фильтр безопасности.

У нас есть один признак:

```
x = количество подозрительных факторов
```

Например:

| Письмо                 |  x | Правильный ответ |
| ---------------------- | -: | ---------------: |
| Обычное письмо         |  0 |                0 |
| Есть внешняя ссылка    |  1 |                1 |
| Ссылка + запрос пароля |  2 |                1 |

Будем использовать:

```
0 = обычное письмо
1 = фишинговое письмо
```

Наша задача – научить нейрон зависимости:

```
больше подозрительных факторов
             ↓
       выше вероятность
             ↓
          phishing
```

Это очень упрощенная модель реальной задачи классификации. В настоящем фильтре будет намного больше признаков.

Но для изучения backpropagation одного признака достаточно.

### Модель одного нейрона

Наш нейрон будет выглядеть так:

```
             x
             |
             v
       +-----------+
       |  Neuron   |
       |           |
       |  weight   |
       |  bias     |
       +-----------+
             |
             v
          sigmoid
             |
             v
        probability
```

Математически нейрон сначала вычисляет:

$$
z = wx+bz = wx + b
$$



где:

* `x` – вход;
* `w` – вес;
* `b` – bias;
* `z` – внутренний сигнал.

Затем применяется функция активации:

$$
a=sigmoid(z)
$$



На выходе получаем число от `0` до `1`.

Например:

```
0.95 → высокая вероятность phishing

0.05 → низкая вероятность phishing
```

Здесь `a` – prediction нейрона.

#### Шаг 1. Создаем класс Neuron

Начнем с минимальной структуры:

```php
class Neuron
{
    private float $weight;

    private float $bias;

    public function __construct()
    {
        $this->weight = mt_rand(-100, 100) / 100;
        $this->bias = 0.0;
    }
}
```

Теперь у нас есть объект, который представляет нейрон.

Он хранит два параметра: `weight` and `bias`

Это и есть параметры модели.

Во время обучения они будут изменяться.

Важно понимать разницу: модель хранит параметры, а обучение изменяет эти параметры.

#### Шаг 2. Forward pass

Сначала научим нейрон делать prediction.

Добавим метод:

```php
public function forward(float $input): float
{
    $z = $this->weight * $input + $this->bias;

    return $this->sigmoid($z);
}
```

Теперь можно сделать:

```php
$neuron = new Neuron();
$result = $neuron->forward(2);

echo $result;
```

Внутри происходит:

```
input = 2
    ↓
2 × weight + bias
    ↓
    z
    ↓
 sigmoid
    ↓
prediction
```

Это называется **forward pass** – прямой проход.

Нейрон получает данные и вычисляет результат.

#### Шаг 3. Функция активации

Используем sigmoid:

```php
private function sigmoid(float $x): float
{
    return 1 / (1 + exp(-$x));
}
```

Sigmoid превращает любое число в значение между `0` и `1`.

Например:

```
sigmoid(-3) ≈ 0.05
sigmoid(0)  = 0.50
sigmoid(3)  ≈ 0.95
```

Это удобно для нашей задачи.

Мы можем интерпретировать результат как вероятность:

```
0.05 → 5% phishing
0.50 → 50% phishing
0.95 → 95% phishing
```

Это еще не означает, что значение действительно является статистически откалиброванной вероятностью. Для нашего учебного примера это удобная интерпретация выхода sigmoid.

#### Шаг 4. Нейрон должен помнить forward pass

Теперь появляется важный момент.

Во время backpropagation нам понадобится информация о предыдущем forward pass.

Нужно знать:

* какой был вход;
* какой получился выход.

Добавим свойства:

```php
private float $lastInput;
private float $lastOutput;
```

И изменим `forward()`:

```php
public function forward(float $input): float
{
    $this->lastInput = $input;
    $z = $this->weight * $input + $this->bias;
    $this->lastOutput = $this->sigmoid($z);

    return $this->lastOutput;
}
```

Теперь нейрон запоминает:

```
forward()
input
  ↓
Neuron
  ↓
output

Neuron remembers:
lastInput
lastOutput
```

Это понадобится на следующем этапе.

#### Шаг 5. Функция ошибки

Нейрон сделал prediction. Но как понять, хороший он или плохой?

Нужно сравнить prediction с правильным ответом.

Используем простую квадратичную функцию ошибки:

$$
L = (a-y)^2
$$



где:

* `a` – prediction
* `y` – правильный ответ
* `L` – loss

Например:

```
prediction = 0.6
target = 1
```

Тогда:

$$
L = (0.6-1)^2 = 0.16
$$

Чем ближе prediction к target, тем меньше ошибка.

Например:

```
prediction = 0.9
target = 1
loss = 0.01
```

А если:

```
prediction = 0.2
target = 1
loss = 0.64
```

Значит, второе предсказание значительно хуже.

#### Шаг 6. Что должен сделать backpropagation?

Теперь начинается самая важная часть кейса.

Мы знаем:

```
prediction
target
loss
```

Но нейрон должен ответить на другой вопрос:

> Как нужно изменить `weight`, чтобы ошибка уменьшилась?

И отдельно:

> Как нужно изменить `bias`?

Для этого используется градиент.

Градиент показывает направление изменения параметра, которое влияет на loss.

В нашем случае нам нужны:

$$
\frac{dL}{dw}
$$

и

$$
\frac{dL}{db}
$$

То есть:

```
как weight влияет на ошибку
как bias влияет на ошибку
```

#### Шаг 7. Цепное правило

Чтобы получить эти градиенты, используем [chain rule](../../../vvedenie/glossarii.md#chain-rule-cepnoe-pravilo) – цепное правило.

Наша модель состоит из нескольких последовательных операций:

```
x
 ↓
z = wx + b
 ↓
a = sigmoid(z)
 ↓
L = (a - y)²
```

Ошибка зависит от `a`.

`a` зависит от `z` , а `z` зависит от `w`.

Поэтому:

$$
\frac{dL}{dw} = \frac{dL}{da} \cdot \frac{da}{dz} \cdot \frac{dz}{dw}
$$

Это и есть идея backpropagation.

Мы начинаем с ошибки и идем назад через вычисления.

```
Loss
 ↑
activation
 ↑
weighted sum
 ↑
weight
```

#### Шаг 8. Первая часть градиента

Наша функция ошибки:

$$
L=(a-y)^2
$$

Производная по `a`:

$$
\frac{dL}{da}=2(a-y)
$$

В PHP:

```php
$dL_da = 2 * ($this->lastOutput - $target);
```

Этот градиент отвечает на вопрос:

> Как изменение prediction влияет на ошибку?

#### Шаг 9. Производная sigmoid

Следующая функция:&#x20;

$$
a=sigmoid(z)
$$

Для sigmoid существует очень удобная производная:

$$
\frac{da}{dz}=a(1-a)
$$

Поэтому:

```php
private function sigmoidDerivative(float $a): float
{
    return $a * (1 - $a);
}
```

А в `backward()`:

```php
$da_dz = $this->sigmoidDerivative(
    $this->lastOutput
);
```

Мы используем уже вычисленный output.

Отдельно пересчитывать `sigmoid(z)` не требуется.

#### Шаг 10. Как вес влияет на z?

У нас:

$$
z=wx+b
$$

Производная по `w`:

$$
\frac{dz}{dw}=x
$$

Это логично.

Если вход `x` большой, изменение веса сильнее влияет на `z`.

В PHP:

```php
$dz_dw = $this->lastInput;
```

Теперь у нас есть все три части цепного правила:

```
dL/da
da/dz
dz/dw
```

Перемножаем:

```php
$this->weightGradient = $dL_da * $da_dz * $dz_dw;
```

Получаем:

$$
\frac{dL}{dw} = \frac{dL}{da} \cdot \frac{da}{dz} \cdot \frac{dz}{dw}
$$

#### Шаг 11. А что с bias?

Bias тоже является параметром модели.

Мы имеем:

$$
z=wx+bz=wx+b
$$



Поэтому:

$$
\frac{dz}{db}=1
$$

Следовательно:

$$
\frac{dL}{db} = \frac{dL}{da} \cdot \frac{da}{dz}
$$

В коде:

```php
$this->biasGradient = $dL_da * $da_dz;
```

Теперь нейрон умеет вычислять градиент для обоих параметров:

```
weight → gradient
bias   → gradient
```

#### Шаг 12. Реализуем backward()

Теперь можем собрать все вместе:

```php
public function backward(float $target): void
{
    $dL_da = 2 * ($this->lastOutput - $target);
    $da_dz = $this->sigmoidDerivative($this->lastOutput);
    $dz_dw = $this->lastInput;

    $this->weightGradient = $dL_da * $da_dz * $dz_dw;
    $this->biasGradient = $dL_da * $da_dz;
}
```

Это и есть наш backpropagation.

Важно: здесь мы еще ничего не изменяем.

Метод `backward()` только вычисляет:

```
какой вклад в ошибку
имеет каждый параметр
```

Изменение параметров произойдет на следующем шаге.

#### Шаг 13. Gradient descent

Теперь нейрон знает градиенты. Осталось изменить параметры.

Используем градиентный спуск:

$$
w=w-\alpha\frac{dL}{dw}
$$

и:

$$
b=b-\alpha\frac{dL}{db}
$$

где `α` – learning rate.

В коде:

```php
public function update(float $learningRate): void
{
    $this->weight -= $learningRate * $this->weightGradient;
    $this->bias -= $learningRate * $this->biasGradient;
}
```

Например:

```php
$neuron->update(0.1);
```

Значение `0.1` – learning rate.

Он определяет размер шага.

Слишком большой шаг может привести к нестабильному обучению.

Слишком маленький – сделать обучение очень медленным.

#### Полный класс Neuron

Теперь соберем все части вместе:

```php
class Neuron
{
    private float $weight;

    private float $bias;

    private float $lastInput;

    private float $lastOutput;

    private float $weightGradient;

    private float $biasGradient;

    public function __construct()
    {
        $this->weight = mt_rand(-100, 100) / 100;
        $this->bias = 0.0;
    }

    public function forward(float $input): float
    {
        $this->lastInput = $input;
        $z = $this->weight * $input + $this->bias;
        $this->lastOutput = $this->sigmoid($z);

        return $this->lastOutput;
    }

    public function backward(float $target): void
    {
        $dL_da = 2 * ($this->lastOutput - $target);
        $da_dz = $this->sigmoidDerivative($this->lastOutput);
        $dz_dw = $this->lastInput;

        $this->weightGradient = $dL_da * $da_dz * $dz_dw;
        $this->biasGradient = $dL_da * $da_dz;
    }

    public function update(float $learningRate): void
    {
        $this->weight -= $learningRate * $this->weightGradient;
        $this->bias -= $learningRate * $this->biasGradient;
    }

    private function sigmoid(float $x): float
    {
        return 1 / (1 + exp(-$x));
    }

    private function sigmoidDerivative(float $a): float
    {
        return $a * (1 - $a);
    }
}
```

Получился очень маленький класс. Но внутри него уже есть основные механизмы обучения нейронной сети.

#### Шаг 14. Создаем обучающую выборку

Теперь дадим нейрону несколько примеров:

```php
$dataset = [
    [0.0, 0.0],
    [1.0, 1.0],
    [2.0, 1.0],
];
```

Первое значение – вход: `x`&#x20;

Второе – правильный ответ: `target`

Получается:

```
x = 0 → 0
x = 1 → 1
x = 2 → 1
```

Это уже немного больше похоже на задачу классификации.

#### Шаг 15. Обучаем нейрон

Создаем модель:

```php
$neuron = new Neuron();
$learningRate = 0.1;
```

Теперь запускаем обучение:

```php
for ($epoch = 1; $epoch <= 1000; $epoch++) {

    $loss = 0.0;

    foreach ($dataset as [$input, $target]) {
        // Forward pass
        $prediction = $neuron->forward($input);
        // Loss
        $loss += ($prediction - $target) ** 2;
        // Backpropagation
        $neuron->backward($target);
        // Gradient descent
        $neuron->update($learningRate);
    }

    if ($epoch % 100 === 0) {
        echo sprintf("Epoch %d, loss: %.4f\n", $epoch, $loss);
    }
}
```

На каждой итерации происходит один и тот же процесс:

```
             input
               ↓
        ┌─────────────┐
        │   forward   │
        └─────────────┘
               ↓
          prediction
               ↓
             loss
               ↓
        ┌─────────────┐
        │  backward   │
        └─────────────┘
               ↓
          gradients
               ↓
        ┌─────────────┐
        │   update    │
        └─────────────┘
               ↓
        new parameters
```

И затем процесс повторяется.

### Что такое эпоха?

В нашем примере одна эпоха означает, что нейрон прошел по всей обучающей выборке.

Например:

```
Dataset:
0 → 0
1 → 1
2 → 1
```

Одна эпоха:

```
0 → forward → backward → update
1 → forward → backward → update
2 → forward → backward → update
```

После этого начинается следующая эпоха.

```
Epoch 1
Epoch 2
Epoch 3
...
Epoch 1000
```

### Что происходит с моделью во время обучения?

Представим, что в начале параметры случайные:

```
weight = -0.4
bias   = 0
```

Нейрон может выдавать плохие predictions:

```
x = 0 → 0.50
x = 1 → 0.40
x = 2 → 0.31
```

Но после backpropagation параметры изменяются.

Например:

```
weight = 0.8
bias   = -0.4
```

Теперь predictions становятся ближе к нужным значениям:

```
x = 0 → около 0.40
x = 1 → около 0.60
x = 2 → около 0.77
```

После дальнейшего обучения параметры продолжают изменяться. Главная идея не в конкретных числах. Главное – направление:

```
bad prediction
      ↓
calculate loss
      ↓
calculate gradients
      ↓
change parameters
      ↓
better prediction
```

### Почему это называется backpropagation?

Потому что информация об ошибке распространяется назад по вычислениям.

Forward pass идет:

```
input
  ↓
  z
  ↓
activation
  ↓
prediction
  ↓
loss
```

Backpropagation идет в обратном направлении:

```
loss
  ↓
activation
  ↓
  z
  ↓
weight / bias
```

В нашем маленьком нейроне это выглядит просто.

Но принцип остается тем же и в большой сети:

```
Output layer
     ↑
Hidden layer
     ↑
Hidden layer
     ↑
Input
```

Ошибка распространяется от выхода назад через сеть.

### Разберем один backward pass вручную

Полезно один раз пройти вычисления полностью.

Пусть:

```
x = 2

target = 1
```

Предположим:

```
weight = 0.5
bias = 0
```

Сначала forward:

\==========

z=wx+bz=wx+b

Получаем:

z=0.5×2=1z=0.5\times2=1

Теперь sigmoid:

a=sigmoid(1)≈0.731a=sigmoid(1)\approx0.731

Prediction:

```
0.731
```

Target:

```
1
```

Loss:

L=(0.731−1)2L=(0.731-1)^2

примерно:

```
0.072
```

Теперь начинаем движение назад.

#### Шаг 1 – ошибка по prediction

dLda=2(a−y)\frac{dL}{da}=2(a-y)

Получаем примерно:

```
-0.538
```

#### Шаг 2 – производная sigmoid

dadz=a(1−a)\frac{da}{dz}=a(1-a)

Получаем примерно:

```
0.197
```

#### Шаг 3 – влияние веса

dzdw=x\frac{dz}{dw}=x

То есть:

```
2
```

#### Шаг 4 – итоговый gradient

Перемножаем:

dLdw=−0.538×0.197×2\frac{dL}{dw} = -0.538 \times 0.197 \times 2

Получаем примерно:

```
-0.212
```

Теперь weight можно обновить.

При:

```
learningRate = 0.1
```

получаем:

wnew=w−0.1×(−0.212)w\_{new}=w-0.1\times(-0.212)

То есть:

```
0.5 + 0.0212

≈ 0.5212
```

Вес немного увеличился.

Именно это и означает обучение.

Нейрон не получает готовый ответ:

> "Твой weight должен быть 0.5212".

Он вычисляет, **в какую сторону и насколько нужно изменить weight**, чтобы уменьшить ошибку.

## Почему gradient имеет знак?

Это важная деталь.

Градиент может быть положительным или отрицательным.

Например:

```
gradient = +0.2
```

означает, что увеличение параметра в текущей точке увеличивает loss.

Поэтому gradient descent уменьшит параметр:

```php
$weight -= 0.1 * 0.2;
```

А если:

```
gradient = -0.2
```

то:

```php
$weight -= 0.1 * (-0.2);
```

и параметр увеличится.

То есть формула:

parameter=parameter−learningRate×gradientparameter = parameter - learningRate \times gradient

автоматически выбирает направление изменения.

| Компонент           | Где реализован               |
| ------------------- | ---------------------------- |
| Weight              | `$weight`                    |
| Bias                | `$bias`                      |
| Forward pass        | `forward()`                  |
| Activation function | `sigmoid()`                  |
| Loss                | `(prediction - target) ** 2` |
| Backpropagation     | `backward()`                 |
| Weight gradient     | `$weightGradient`            |
| Bias gradient       | `$biasGradient`              |
| Gradient descent    | `update()`                   |
| Learning rate       | `$learningRate`              |

Это уже не просто математическая демонстрация.

Это работающая минимальная модель машинного обучения.

***

## Один нейрон – это уже нейронная сеть?

Формально один нейрон можно рассматривать как простейшую нейронную модель.

Но его возможности очень ограничены.

Наш нейрон имеет:

```
1 input
1 weight
1 bias
1 output
```

То есть:

```
x
 ↓
Neuron
 ↓
prediction
```

Настоящая нейронная сеть выглядит значительно сложнее:

```
inputs
  ↓
┌───────────────┐
│ Hidden Layer  │
│ ○ ○ ○ ○ ○     │
└───────────────┘
  ↓
┌───────────────┐
│ Hidden Layer  │
│ ○ ○ ○ ○       │
└───────────────┘
  ↓
┌───────────────┐
│ Output Layer  │
│ ○ ○           │
└───────────────┘
  ↓
prediction
```

Но принцип обучения остается тем же.

## Связь с настоящими ML-библиотеками

Наш собственный класс:

```
Neuron

forward()
backward()
update()
```

В более серьезной ML-системе мы увидим похожие этапы:

```
Layer
   ↓
forward()

Loss
   ↓
gradient

Layer
   ↓
backward()

Optimizer
   ↓
step()
```

Например, optimizer отвечает за обновление параметров.

В нашем случае мы сами написали простейший gradient descent:

```php
$this->weight -=
    $learningRate * $this->weightGradient;
```

В реальной библиотеке этим занимается специальный компонент.

Разница прежде всего в масштабе и количестве параметров.

Наш пример:

```
1 input
1 weight
1 bias
```

Большая нейронная сеть:

```
тысячи или миллионы параметров
```

Но базовая идея остается:

```
forward
   ↓
loss
   ↓
backward
   ↓
gradients
   ↓
update
```

## Почему мы не используем RubixML?

Потому что цель этого кейса – понять механизм.

Когда мы используем готовую библиотеку, мы можем написать несколько строк:

```php
$model->train($dataset);
```

И модель обучится.

Но за этой простой строкой скрывается большое количество математики:

```
forward pass
loss calculation
derivatives
chain rule
backpropagation
gradient descent
parameter updates
```

После реализации собственного нейрона становится намного понятнее, что происходит внутри библиотеки.

Мы не собираемся писать production ML framework на чистом PHP.

Наша задача другая:

> снять магию с процесса обучения.

***

## Важное ограничение нашего примера

Наш нейрон намеренно очень простой.

У него только один вход:

```
x
```

Поэтому он может увидеть только один фактор.

Реальный phishing classifier может использовать десятки или сотни признаков:

```
number of links
sender reputation
domain age
contains password request
contains suspicious words
URL features
HTML features
...
```

Тогда вход будет выглядеть примерно так:

```
x1
x2
x3
x4
...
xn
```

А нейрон будет вычислять:

z=w1x1+w2x2+⋯+wnxn+bz=w\_1x\_1+w\_2x\_2+\dots+w\_nx\_n+b

Но backpropagation останется тем же.

Для каждого веса нужно определить:

```
насколько этот weight повлиял на loss
```

И затем изменить его.

***

## Еще одно важное ограничение

Наш пример с одним нейроном специально упрощен.

Мы используем один признак и простую зависимость:

```
0 → обычное письмо

1 → подозрительное

2 → подозрительное
```

Такой нейрон не может решать сложные задачи.

Он не понимает текст.

Он не видит контекст.

Он не знает, что такое phishing.

Он просто подбирает параметры математической функции так, чтобы уменьшить ошибку на обучающих данных.

И это очень важная мысль:

> Нейрон не "понимает" задачу в человеческом смысле. Он изменяет параметры математической модели на основе ошибки.

***

## Главное, что нужно запомнить

Backpropagation – это не магическая технология.

Это способ вычислить:

> Как каждый параметр модели повлиял на ошибку?

Для нашего нейрона процесс выглядит так:

```
1. Получить input
        ↓
2. Вычислить prediction
        ↓
3. Посчитать loss
        ↓
4. Пройти назад через вычисления
        ↓
5. Получить gradients
        ↓
6. Изменить weight и bias
        ↓
7. Повторить
```

Именно это является сердцем обучения нейронной сети.

Самая важная формула нашего кейса:

dLdw=dLda⋅dadz⋅dzdw\frac{dL}{dw} = \frac{dL}{da} \cdot \frac{da}{dz} \cdot \frac{dz}{dw}

Она показывает всю идею backpropagation в одном выражении.

Мы начинаем с ошибки и с помощью цепного правила постепенно движемся назад к параметрам модели.

В предыдущем кейсе мы видели нейрон как функцию:

```

  ↓

  ↓

```

Теперь мы добавили вторую половину:

  ↓

  ↓

Теперь нейрон не просто делает prediction.

Он способен **учиться на своих ошибках**.

Это принципиальный переход от простой математической функции к обучаемой модели.

## От одного нейрона к настоящей сети

Наш `Neuron` – это минимальная модель.

Следующий шаг – соединить несколько нейронов.

Например:

```
             ┌── Neuron ──┐
input ───────┼── Neuron ──┼── output
             └── Neuron ──┘
```

А затем добавить несколько слоев:

```
Input
  ↓
Hidden Layer
  ↓
Hidden Layer
  ↓
Output
```

Тогда backpropagation должен будет передавать градиенты не только через один нейрон, но через всю сеть.

Именно это мы увидим в следующем кейсе.

Backpropagation – это не отдельная магическая технология.

Это метод, который говорит нейрону:

“Посмотри на свою ошибку, вычисли свой вклад в нее и немного измени свои параметры”.

В следующем кейсе мы заменим один наш объект `Neuron` на настоящую многослойную сеть и посмотрим, как тот же механизм используется внутри RubixML.
