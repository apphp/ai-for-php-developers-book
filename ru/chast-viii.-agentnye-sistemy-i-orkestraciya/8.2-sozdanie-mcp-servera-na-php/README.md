# 8.2 Создание MCP-сервера на PHP

До этого мы говорили о том, как AI-модели работают с информацией, создают ответы и взаимодействуют с приложениями через API. Но что, если дать модели возможность не только отвечать на вопросы, но и самостоятельно обращаться к другим системам, использовать инструменты и выполнять различные задачи?

Именно для этого существует [**Model Context Protocol**](../../vvedenie/glossarii.md#model-context-protocol-mcp) **(MCP)**. Это открытый протокол, который позволяет AI-приложениям взаимодействовать с внешними сервисами и инструментами по единому стандарту.

{% hint style="info" %}
### Историческая справка

Model Context Protocol был представлен компанией Anthropic 25 ноября 2024 года. Изначально протокол создавался как открытый стандарт, который должен был упростить подключение AI-ассистентов к внешним источникам данных, инструментам и приложениям.

Идея оказалась востребованной: MCP начал быстро распространяться за пределами экосистемы Anthropic. В декабре 2025 года протокол был передан под управление Agentic AI Foundation при Linux Foundation, чтобы его дальнейшее развитие оставалось открытым и независимым от одной компании.

Подробнее:

* [Передача MCP в Agentic AI Foundation](https://www.anthropic.com/news/donating-the-model-context-protocol-and-establishing-of-the-agentic-ai-foundation?utm_source=chatgpt.com).
{% endhint %}

Раньше для подключения каждого AI-клиента к внешнему сервису часто приходилось писать отдельную интеграцию. MCP упрощает эту задачу: достаточно реализовать MCP-сервер, который предоставит нужные возможности, и разные AI-приложения смогут с ним работать.

Для PHP-разработчиков это особенно интересно. Не нужно переписывать существующее приложение на Python или другом языке. Можно использовать уже готовый PHP-код, бизнес-логику и API, добавив к ним возможность взаимодействия с AI-инструментами.
