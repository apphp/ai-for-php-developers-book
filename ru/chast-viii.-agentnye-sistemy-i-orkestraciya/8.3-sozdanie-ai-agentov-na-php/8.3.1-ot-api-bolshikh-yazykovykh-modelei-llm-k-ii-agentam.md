# 8.3.1 От API больших языковых моделей (LLM) к ИИ-агентам

В этом разделе разберём, чем обычное взаимодействие с LLM через API отличается от работы AI-агента. Обычная модель получает запрос и возвращает ответ, тогда как агент может самостоятельно определять последовательность действий, использовать инструменты и учитывать результаты предыдущих шагов. Познакомимся с основными компонентами агента, его циклом работы (Agent Loop), принципами принятия решений и выполнением многошаговых задач. Наша цель – понять, как перейти от простого вызова LLM API к созданию системы, способной выполнять более сложные задачи с минимальным вмешательством пользователя.
