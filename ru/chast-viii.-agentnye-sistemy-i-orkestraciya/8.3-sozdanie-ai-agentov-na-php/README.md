# 8.3 Создание AI-агентов на PHP

Обычное взаимодействие с языковой моделью обычно выглядит достаточно просто: приложение отправляет запрос, получает ответ и показывает его пользователю. Но что происходит, когда задача требует нескольких последовательных действий, обращения к разным источникам данных или использования внешних инструментов?

Здесь на помощь приходят AI-агенты. В отличие от обычного вызова LLM API, агент может анализировать задачу, выбирать подходящие инструменты, выполнять действия, оценивать результаты и определять следующие шаги. Это позволяет создавать приложения, способные решать более сложные задачи, чем простая генерация текста.

Для создания таких систем не обязательно использовать Python или специализированные платформы. PHP предоставляет всё необходимое для работы с LLM API, реализации логики агентов и подключения внешних инструментов.

В этой главе мы разберём основные принципы работы AI-агентов, познакомимся с Function Calling и научимся интегрировать MCP-инструменты. Затем создадим собственного AI-агента на PHP, который сможет самостоятельно выбирать и использовать инструменты для выполнения задач пользователя.
