# 8.3.3. Практические кейсы

В этом практическом примере создадим полноценного AI-агента на PHP, который сможет выполнять задачи пользователя с помощью LLM и внешних инструментов. В качестве примера используем помощника интернет-магазина, способного искать товары, проверять заказы и отвечать на вопросы покупателей. Реализуем Agent Loop, подключим Function Calling и MCP-инструменты, а также покажем, как агент выбирает последовательность действий и использует результаты предыдущих операций. Дополнительно рассмотрим управление контекстом, обработку ошибок и ограничения количества шагов. В результате получим работающего AI-агента, объединяющего изученные ранее технологии.
