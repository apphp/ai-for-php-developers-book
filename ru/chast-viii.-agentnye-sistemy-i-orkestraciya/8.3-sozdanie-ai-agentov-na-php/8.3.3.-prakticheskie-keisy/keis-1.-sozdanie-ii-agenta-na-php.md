# Кейс 1. Создание ИИ-агента на PHP

\
Создаём агента, который получает задачу на естественном языке и самостоятельно выбирает инструменты для её выполнения.

Например:

> Find my last order and tell me whether it has been shipped.

Агент должен:

1. Понять запрос.
2. Выбрать подходящий инструмент.
3. Выполнить вызов.
4. Получить результат.
5. Сформировать ответ пользователю.

Здесь мы объединяем LLM API, Function Calling, Agent Loop и MCP.
