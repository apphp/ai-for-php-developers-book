# 8.3.2 Вызов функций и интеграция инструментов MCP

В этом разделе рассмотрим, как AI-модели могут взаимодействовать с внешними функциями и инструментами. Познакомимся с Function Calling (Tool Calling), разберём, как модель выбирает подходящий инструмент, формирует аргументы вызова и обрабатывает полученный результат. На примерах PHP покажем полный цикл взаимодействия между LLM, приложением и инструментами. Затем рассмотрим, как расширить возможности агента с помощью MCP и подключать инструменты, предоставляемые внешними MCP-серверами. Особое внимание уделим различиям между обычными PHP-функциями, Function Calling и MCP, а также тому, как эти механизмы дополняют друг друга.
